# 💰 Coingame

Coingame (placeholder title) is a fun, multiplayer game where players compete to survive rounds by strategically betting their coins. This project is a work in progress.

-----

## 🚀 Getting Started

This project is a [Next.js](https://nextjs.org/) application. To get it running locally, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/Olaelve5/coingame.git
    ```
2.  **Navigate to the project directory and install dependencies for both the app and the server:**
    ```bash
    # Install app dependencies
    cd coingame/app
    npm install

    # Install server dependencies
    cd ../server
    npm install
    ```
3.  **Run the development servers:**
    ```bash
    # Run the Next.js app
    cd ../app
    npm run dev

    # Run the server
    cd ../server
    npm start
    ```

Open [http://localhost:3000](https://www.google.com/search?q=http://localhost:3000) with your browser to see the result.

-----

## 🎮 How to Play

The game is simple:

1.  **Join a game:** Players join a game lobby using a unique game code.
2.  **Bet your coins:** In each round, players secretly bet a number of their coins.
3.  **Elimination:** The players who bet the fewest coins are eliminated.
4.  **Survive:** The last player standing wins\!

## 🛠️ Tech Stack

This project is built with the following technologies:

### Frontend

  * **Framework:** [Next.js](https://nextjs.org/) (with Turbopack)
  * **Language:** [TypeScript](https://www.typescriptlang.org/)
  * **State Management:** [Zustand](https://github.com/pmndrs/zustand)
  * **Animation:** [Framer Motion](https://www.framer.com/motion/)
  * **Real-time Communication:** [Socket.IO Client](https://socket.io/docs/v4/client-api/)
  * **UI Components:** [Mantine](https://mantine.dev/)
  * **Icons:** [FontAwesome](https://fontawesome.com/), [Tabler Icons](https://tabler-icons.io/)

### Backend

  * **Runtime:** [Node.js](https://nodejs.org/)
  * **Framework:** [Express](https://expressjs.com/)
  * **Language:** [TypeScript](https://www.typescriptlang.org/)
  * **Database:** [MongoDB](https://www.mongodb.com/) with [Mongoose](https://mongoosejs.com/)
  * **Real-time Communication:** [Socket.IO](https://socket.io/)
